# SWINE SYNC — ส่งมอบให้บริษัท

แดชบอร์ดติดตามฟาร์มสุกรของ CPF ที่กำแพงเพชร — **โค้ดทั้งหมด + เอกสารส่งมอบทั้งหมด** อยู่ในรีโปนี้

## เริ่มอ่านที่ไหน

| ถ้าคุณคือ | เริ่มที่ |
| --- | --- |
| **คนที่มารับดูแลระบบต่อ** | [เอกสารส่งมอบ — สารบัญ](docs/ส่งมอบ/README.md) |
| **คนที่จะพัฒนาโค้ดต่อ** | [วิธีติดตั้งและเปิดใช้งาน](docs/ส่งมอบ/02-เริ่มต้นใช้งาน.md) → [กติกาหน้าจอ](docs/DESIGN.md) |
| **ไม่เคยใช้ Git มาก่อน** | [คู่มือ GitHub สำหรับผู้เริ่มต้น](docs/ส่งมอบ/03-คู่มือ-GitHub.md) |

## เปิดขึ้นมาดูเร็ว ๆ

```bash
npm install
```

```bash
npm run dev
```

เปิด `http://localhost:5173` แล้วกด **"เข้าชมข้อมูลตัวอย่าง โดยไม่ต้องเข้าสู่ระบบ"**
เท่านี้เห็นหน้าจอครบทุกหน้าโดยยังไม่ต้องตั้งค่าอะไร
(จะรันทั้งระบบพร้อมฐานข้อมูลและ API ดู [ข้อ 2](docs/ส่งมอบ/02-เริ่มต้นใช้งาน.md))

```bash
npm test        # 893 ข้อ ต้องผ่านทั้งหมดก่อน commit
npm run build
npm run lint
```

## ★★ ไม่มีรหัสผ่านหรือกุญแจอยู่ในรีโปนี้เลยสักตัว

ตรงไหนที่จำเป็นต้องใช้ จะเขียนเป็นช่องว่างในวงเล็บมุม `<…>` หรือเว้นค่าว่างไว้ให้เติม

- ค่าที่ต้องใส่ก่อนระบบจะทำงานได้ อยู่ครบใน [`.env.example`](.env.example)
  คัดลอกเป็น `.env` แล้วใส่ค่าจริง — **`.env` ห้าม commit** (กันไว้ใน `.gitignore` แล้ว)
- รายการว่าต้องขอค่าไหนจากใคร อยู่ใน
  [11 · เอกสารอ้างอิง หัวข้อ 11.5](docs/ส่งมอบ/11-เอกสารอ้างอิง.md)
- ไม่ใส่ค่าไหน ส่วนนั้นจะปิดตัวเองและบอกเหตุผล **ไม่ได้ทำให้ทั้งระบบล้ม**
  เช่นไม่ใส่โทเคนไลน์ = ไม่ส่งไลน์ แต่หน้าเว็บกับการแจ้งเตือนในแอปยังทำงานปกติ

## ของที่ตั้งใจไม่ใส่มาในรีโปนี้

| ไม่ใส่ | เพราะ |
| --- | --- |
| บันทึกงานภายใน (`TASKS.md`) | เป็นบันทึกภายในของผู้พัฒนาเดิม เขียนด้วยถ้อยคำของคนทำงาน ไม่ใช่เอกสารส่งมอบ · ขอได้ถ้าต้องใช้ |
| **รหัสผ่าน · กุญแจ · โทเคน** | อยู่ในรีโปแยกชื่อ **`SWINE-SYNC-SECRET`** (private) · ค่าจริงอยู่ในก้อนที่เข้ารหัส และ **รหัสที่เปิดก้อนเดินคนละทาง** — ขอจากผู้ดูแลระบบเดิม |
| วิธีทำงานของ **ท่อรับค่าจากเซนเซอร์** | ท่อนั้นเป็นของทีมอื่น ไม่ใช่ของระบบนี้ · `docs/RUNBOOK.md` จึงบอกแค่ว่า**ค่ามาจากไหน** ไม่ได้บอกว่าท่อทำงานยังไง |
| ภาพออกแบบชุดเก่า | เป็นภาพ**ม็อกอัพ** ไม่ใช่หน้าจอจริง ใส่มาแล้วจะเข้าใจผิดว่าระบบหน้าตาแบบนั้น |
| สำเนาหลังบ้านชุดเก่า | ซ้ำกับ `server/` และเก่ากว่า |
