## 6.4 ★ จุดที่ "ข้อมูลชุดเดียวกันอยู่หลายไฟล์" — พลาดแล้วพังเงียบ

นี่คือรายการที่เคยทำให้เสียเวลาจริง **แก้ที่เดียวไม่พอ**

| เพิ่มอะไร | ต้องแก้ที่ไหนบ้าง |
| --- | --- |
| **ชนิดบันทึกงานในเล้าแบบใหม่** | 1. migration แก้ CHECK ของ `barn_log.type`<br/>2. `server/src/barnlog/validate.js`<br/>3. `src/lib/barnLogTypes.js`<br/>4. `server/src/line/intent.js`<br/>5. `server/src/line/recordText.js` |
| **ชนิดข้อความไลน์แบบใหม่** | 1. migration แก้ CHECK ของ `line_notice.kind`<br/>2. `server/src/line/notifier.js` |
| **หน้าเว็บใหม่** | 1. `src/pages/`<br/>2. route ใน `src/App.jsx`<br/>3. `DEFAULT_LAYOUTS` ใน `src/lib/layout/presets.js` |
| **ข้อความใหม่บนหน้าจอ** | ต้องผ่าน `t()` และเติมคำแปล **อังกฤษ + จีน** |
| **ปุ่มที่เขียนข้อมูล** | เช็ก `useAuth().can(...)` **และ** `requireRole` ฝั่งเซิร์ฟเวอร์ |

★★ **บทเรียนที่แพงที่สุดของโปรเจกต์นี้: เพิ่มค่าใหม่ลงคอลัมน์ ต้องดู CHECK constraint ก่อนเสมอ**
เคยใส่ค่าใหม่ลง `line_notice.kind` โดยไม่ดู ตัวส่ง**ส่งออกสำเร็จก่อน** แล้วพังตอนบันทึก
ตัวชี้จึงไม่ขยับ รอบหน้าส่งซ้ำอีก วนทุก 30 วินาที — **เสียโควตาไลน์ไป 177 ข้อความ**
