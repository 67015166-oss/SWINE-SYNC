## 10.4 ★★ สองเรื่องที่ขวางการส่งมอบ — ต้องเสร็จก่อนจบ

### 1. ก้อนความลับ — มีที่เก็บแล้ว เหลือใส่ของกับส่งรหัส

ถ้าวันนั้นมีคนเดียวที่เปิดก้อนนี้ได้ **บริษัทจะดูแลระบบต่อไม่ได้เลย**

➜ ทำที่เก็บไว้แล้วเมื่อ 6 พ.ย. 2569 — รีโป private แยกชื่อ **`SWINE-SYNC-SECRET`**
มีรายการค่าทั้งหมด แบบไฟล์เปล่า และสคริปต์ทำ/เปิด/ตรวจก้อน **แต่ยังไม่มีค่าจริงอยู่ในนั้น**

| เหลืออะไร | ใครทำ |
| --- | --- |
| ปิดผนึกก้อนใบใหม่แล้ว push ขึ้นรีโปนั้น | ผู้ดูแลระบบเดิม (ต้องเป็นคนที่ถือรหัส) |
| ส่งรหัสที่เปิดก้อน | ⚠ **ตัวต่อตัว ห้ามลงกลุ่มรวม ห้ามส่งทางเดียวกับลิงก์รีโป** |
| ให้สิทธิ์รีโปนั้นกับคนของบริษัทอย่างน้อยสองคน | ผู้ดูแลระบบของบริษัท |

★ ก้อนที่ทำไว้ล่าสุด (28 ต.ค. 2569) **เก่ากว่า `.env` ของกล่องซึ่งถูกแก้ 2 พ.ย.**
กู้ตามใบนั้นจะได้ระบบที่ขาดค่า ➜ ต้องทำใบใหม่ก่อนส่ง (`ops/status.sh` ในรีโปนั้นตรวจให้)

### 2. รีโปยังอยู่บัญชีส่วนตัว

ตอนนี้อยู่ที่ GitHub private `<บัญชีส่วนตัวของผู้พัฒนาเดิม>` ซึ่งเป็นบัญชีส่วนตัว
➜ ต้อง **สร้างรีโปเปล่าแล้ว push ไม่ใช่ transfer**

## 10.8 ข้อเสนอแนะสำหรับการพัฒนาต่อ

1. **อย่าเพิ่ม dependency ใหม่โดยไม่จำเป็น** — ตอนนี้หน้าบ้านมีแค่ 4 ตัว ทำให้ `npm install`
   เร็วและปัญหาเรื่องเวอร์ชันแทบไม่มี เป็นข้อได้เปรียบที่เสียไปง่ายมาก
2. **เขียนเทสต์คู่กับทุกบทเรียน** — ทุกบั๊กในข้อ 9 มีเทสต์คุมไว้แล้ว ทำแบบเดิมต่อไป
3. **แต่อย่าเชื่อเทสต์อย่างเดียว** — งานที่แตะของจริง (ไลน์ · กล้อง · กล่อง) ต้องลองของจริงด้วย
4. **เขียนเหตุผลลง `docs/TASKS.md` ทุกครั้ง** โดยเฉพาะ **อะไรที่ลองแล้วไม่ได้ผล**
   คนถัดไปจะได้ไม่เสียเวลาซ้ำ
5. **เวลาระบบเงียบ ให้เขียนตามอาการ อย่าเดาสาเหตุ** — "ไม่ตอบ" ไม่เท่ากับ "ดับ"
