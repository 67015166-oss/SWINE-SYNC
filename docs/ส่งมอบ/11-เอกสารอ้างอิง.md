## 11.5 ★★ ของที่ต้องขอเพิ่ม — เอกสารชุดนี้ไม่มีให้โดยตั้งใจ

**เอกสารชุดนี้ไม่มีรหัสผ่าน กุญแจ โทเคน หรือที่อยู่สำหรับเข้าระบบอยู่เลยสักตัว**
ตรงไหนที่จำเป็นต้องใช้ จะเขียนเป็นช่องว่างในวงเล็บมุม `<…>` ไว้ให้เติมแทน

| ช่องว่างในเอกสาร | ต้องเติมอะไร | ขอจากใคร |
| --- | --- | --- |
| `<ที่อยู่รีโปของบริษัท>` | ที่อยู่ GitHub ของรีโปที่บริษัทสร้างขึ้นใหม่ | ผู้ดูแลระบบของบริษัท |
| `<ที่อยู่ของกล่อง>` | ที่อยู่ของกล่อง `box-mew` ในเครือข่าย Tailscale | ผู้ดูแลระบบเดิม |
| `<บัญชีส่วนตัวของผู้พัฒนาเดิม>` | ที่อยู่รีโปเดิม ใช้เฉพาะตอนย้ายโค้ดครั้งแรก | ผู้ดูแลระบบเดิม |

### ค่าที่ต้องใส่ในไฟล์ `.env` ก่อนระบบจะทำงานได้

ไฟล์ `.env` **ไม่อยู่ใน Git โดยตั้งใจ** ต้องขอตัวจริงมาวางเอง
รายชื่อค่าทั้งหมดพร้อมคำอธิบายอยู่ใน [ข้อ 8](08-container-และบริการ.md)
ค่าที่ขาดไม่ได้มีดังนี้

| ต้องใส่อะไร | ใช้ทำอะไร | ขอจากใคร |
| --- | --- | --- |
| **ใส่รหัสผ่านฐานข้อมูล** (`POSTGRES_PASSWORD`) | ต่อฐานข้อมูลหลัก | ผู้ดูแลระบบเดิม |
| **ใส่รหัสผ่านผู้ดูแลระบบคนแรก** (`ADMIN_PASSWORD`) | สร้างบัญชีแรกตอนติดตั้งใหม่ | ตั้งใหม่เองได้ |
| **ใส่โทเคนของบัญชีไลน์** (`LINE_CHANNEL_ACCESS_TOKEN` · `LINE_CHANNEL_SECRET`) | ส่งแจ้งเตือนและรับข้อความจากไลน์ | คอนโซล LINE ของฟาร์ม |
| **ใส่ API key ของ AI ฟาร์ม** (`CPF_AI_API_KEY`) | ให้ผู้ช่วยในแอปตอบคำถามได้ | ทีมที่ดูแล AI ของฟาร์ม |
| **ใส่บัญชีของ Voice AI** (`FARMY_USERNAME` · `FARMY_PASSWORD`) | ต่อหน้า Voice AI | ทีม Farmy |
| **ใส่ `HUB_KEY_SECRET`** | ตัวถอดกุญแจของตู้กลาง | ★★ **หายแล้วกู้ไม่ได้** ต้องออกกุญแจใหม่ให้ทุกทีม |

★ ไม่ใส่ค่าไหน ส่วนนั้นจะปิดตัวเองและบอกเหตุผล **ไม่ได้ทำให้ทั้งระบบล้ม**
เช่นไม่ใส่โทเคนไลน์ = ไม่ส่งไลน์ แต่หน้าเว็บกับการแจ้งเตือนในแอปยังทำงานปกติ

## 11.6 ★ ความลับอยู่ที่ไหน

| อะไร | อยู่ที่ไหน |
| --- | --- |
| `.env` ของแดชบอร์ด | เครื่องที่ใช้พัฒนา + บนกล่อง — **ไม่อยู่ใน Git** |
| กุญแจของตู้กลาง | ดูได้ที่หน้า `/hub` → "ดูกุญแจ" |
| `HUB_KEY_SECRET` | ★★ **หายแล้วกู้ไม่ได้** ถ้าหายต้องออกกุญแจใหม่ให้ทุกทีม |
| กุญแจ AI ของฟาร์ม | `.env` ฝั่งเซิร์ฟเวอร์เท่านั้น |
| โทเคนของไลน์ | `.env` · ตั้งผ่าน `ops/set-line-secret.sh` |

⚠ **กติกาเรื่องความลับที่ห้ามละเมิด**

1. **ส่งกุญแจตัวต่อตัว ห้ามลงกลุ่มรวม**
2. **ห้ามพิมพ์รหัสผ่านหรือกุญแจลงในแชท เอกสาร หรือไฟล์ที่อยู่ใน Git**
3. **ห้ามเก็บ `HUB_KEY_SECRET` ไว้ที่เดียวกับไฟล์สำรองฐานข้อมูล**
