## ★ สามเรื่องที่ต้องรู้ก่อนเชื่ออะไรในเอกสารนี้

1. **ตัวเลขทุกตัวในเอกสารนี้วัดจากระบบจริงเมื่อ 5 พ.ย. 2569** ไม่มีค่าสมมติ
   ภาพหน้าจอเป็นภาพจากโปรแกรมจริงที่รันอยู่ ไม่ใช่ภาพออกแบบ
2. **ค่าเซนเซอร์ใหม่ยังไม่เข้ามาตั้งแต่ 5 พ.ย. 02:12** — ตู้ที่ฟาร์มหยุดส่ง
   **ไม่ใช่โปรแกรมพัง** ดู [ข้อ 9](09-ปัญหาและแนวทางแก้.md)
3. **ข้อค้างที่สำคัญที่สุดคือก้อนความลับและที่อยู่ของรีโป**
   อยู่ใน [ข้อ 10](10-สถานะงานและงานต่อไป.md)
