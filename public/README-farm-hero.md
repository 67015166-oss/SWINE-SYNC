# ภาพพื้นหลังหน้าเข้าสู่ระบบ

วางไฟล์ภาพถ่ายฟาร์มไว้ในโฟลเดอร์นี้โดยตั้งชื่อว่า **`farm-hero.jpg`**
(รองรับ `farm-hero.png` และ `farm-hero.webp` ด้วย — โค้ดจะไล่ลองตามลำดับนี้)

- ขนาดที่แนะนำ: กว้าง 1920–2400px อัตราส่วนแนวนอน (ประมาณ 16:9)
- ไฟล์ควรไม่เกิน ~600KB เพื่อให้หน้า login ขึ้นเร็ว (jpg คุณภาพ ~80)
- ถ้าไม่มีไฟล์นี้ หน้า `/login` จะใช้ภาพวาด `src/components/ui/FarmScene.jsx` แทนอัตโนมัติ
  ไม่ต้องแก้โค้ดใด ๆ ทั้งสองทาง

จุดที่โค้ดอ้างถึงไฟล์นี้: ค่าคงที่ `FARM_PHOTOS` ใน `src/pages/Login.jsx`
ส่วนความเข้มของม่านขาวที่คลุมภาพอยู่ที่ `.login-stage.has-photo .login-veil` ใน `src/pages/Login.css`
